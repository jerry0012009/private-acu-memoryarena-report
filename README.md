## 主要发现

| 口径 | 题数 | 原生任务分 A / B ↑ | 偏好违背率 A / B ↓ |
|---|---:|---:|---:|
| 原始实验全量 | 415 | 95.66% / 29.64% | 67.47% / 81.93% |
| 原始实验，仅取对应重算的题目 | 377 | 95.49% / 27.85% | 68.17% / 83.82% |
| 重算实验 | 377 | 92.57% / 89.39% | 87.27% / 88.33% |

在两轮都跑过的 377 道题上，A/B 原生分差从 **67.64** 缩到 **3.18** 个百分点，主要来自 B 组恢复。重算中，原先召回但没收到建议的 86 道 A 组题全部在首个可见动作前收到开场建议；这批题的 A 组违背率仍高于 B。两轮改变了执行时间、路由和建议时序，重算中实际通道也可以不同，因此这里的分数不是记忆收益的因果估计。
